# 6 meses a tu lado ♡

Página web romántica para celebrar medio año de relación. Hecha con HTML, CSS y JavaScript, sin instalar dependencias.

## Cómo abrirla
Abre `index.html` en un navegador o desde Visual Studio Code con Live Server.

## Funciones
- Portada con fotografía personal y reproductor de música.
- Lista de reproducción: añadir varias canciones, seleccionar pistas, pasar a anterior/siguiente y repetir.
- Nuestra historia con una foto y recuerdos.
- Razones por las que te amo, una por una al pulsar la tarjeta.
- Momentos especiales: álbum de fotos estilo Polaroid.
- Sorpresa: «¿Quieres ver algo increíble?». Al pulsar Sí, aparece «Así es como mi cámara te ve» y a los seis segundos «Así es como te miran mis ojos siempre» con una segunda foto.
- Cartita desplegable.
- Animaciones suaves al desplazarte y diseño adaptable a celular.

## Fotos y canciones
Las fotos y canciones que se cargan desde los botones se guardan **solo en el almacenamiento local del navegador**. No se suben automáticamente a GitHub ni aparecerán en el teléfono de otra persona. Para compartir la versión definitiva con medios propios, intégralos en los archivos del proyecto.

**Importante:** el repositorio es público. No publiques fotografías privadas ni canciones comerciales sin las autorizaciones correspondientes.

## Publicar con GitHub Pages
Ve a **Settings → Pages → Build and deployment → Deploy from a branch**. Selecciona `main` y la carpeta `/(root)`, después guarda los ajustes. GitHub asignará un enlace al publicarse. El audio puede requerir que la persona pulse reproducir por las restricciones del navegador.
